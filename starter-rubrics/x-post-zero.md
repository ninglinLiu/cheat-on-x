# Starter Rubric：X 帖子（单帖 / thread / 引用 / 回复）— v0 cold-start 占位

**这是给还没有校准数据的 X 账号用的占位 rubric。它会打错。**前 5 条预测中枢误差大概 ±60%——这是 cold-start 的数学事实，不是 rubric 失败。

X 发帖快，样本攒得也快：日更 3 条的账号，两周就有 30+ 条复盘。跑完 5 条完整闭环（预测 → 发 → 复盘）后可以提议第一次 `/cheatx-bump`。

> 本文件会被复制成你项目里的 `rubric_notes.md`，它是 blind 打分 sub-agent **唯一**能读的规则文件。所以这里只放通用语言：公式、维度定义、bucket 规则。**不要**往里写具体帖子、链接、复盘数字、回复原文——那些写 `rubric-memo.md`。

---

## 维度从哪来

X 的 For You 排序（xai-org/x-algorithm，2026-01 开源）不是一个"热度分"。Phoenix 模型对每条候选帖预测一组行为概率，再按权重求和：

- 正向：点赞、回复、转发、引用、分享（私信 / 复制链接）、点进帖子、点主页、点链接、展开图片、停留时长、关注作者
- 负向：不感兴趣、静音作者、屏蔽作者、举报、没停留就划走

另外几条排序事实会影响你怎么发：
- 超过 48 小时的帖子会被 For You 候选过滤丢掉
- 同一作者连续出现在一个人的时间线里，后面的帖子分数按衰减系数打折
- 非关注者看到你的帖子（out-of-network）有一个折扣系数——破圈要靠内容本身的行为概率够高
- 低曝光的新作者有一个往上提的补偿

权重值没有随代码公开。所以 v0 不假装知道权重——7 个正向维度**等权**，负向风险单独扣分。你的账号的真实权重从你自己的复盘数据里反推（`/cheatx-bump`）。

---

## v0 综合分公式（等权占位）

```
composite = (HK + RP + SV + RS + DW + FT + NF) / 7 × 2.0  −  NR × 0.4
```

- 每个维度 0-5 整数分
- composite 范围 0-10（低于 0 记 0）
- NR 是**风险**：0 = 没有风险，5 = 很可能招来"不感兴趣 / 静音 / 屏蔽 / 举报"
- 0.4 是占位系数：NR=5 时扣 2 分。第一次 bump 时它是重点复审项

## 8 个维度

### HK — Hook（首屏钩子）
*信息流里只露出第一屏（单帖前 1-2 行 / thread 第一条 / 长帖"显示更多"之前 / 配图），能不能让拇指停下来？*

对应行为：停留、点进帖子、展开图片；反面是"没停留就划走"。

- **0** — 通用开头（"今天想聊聊……"、"分享一个观点"）；或者第一行只是铺垫
- **3** — 有一个具体的断言、数字或反常识点，但要读到第二句才知道为什么值得看
- **5** — 第一行本身就是完整、具体、无法忽略的信息（一个数字 + 一个反差 / 一个让人想反驳或想收藏的断言），配图（如有）独立就能看懂

不要把 HK 和"标题党"混为一谈：靠夸张骗点击、正文兑现不了的，HK 给高分的同时 NR 也要给高分。

### RP — Reply pull（回复牵引）
*读完的人有没有想说点什么？——有话可接、有立场可选、有经验可补充。*

对应行为：回复。作者回复别人的回复会让对话继续，这条帖子在每个参与者的时间线里都会多一次出现机会。

- **0** — 封闭陈述，读完只能点赞或划走
- **3** — 一个可以表态的观点，但大多数人只会默默同意
- **5** — 自然留出缺口：一个有分歧但不撕裂的判断 / 一个人人有自己版本的经历 / 一个具体到能被补充或纠错的清单

**不算 RP**："评论区告诉我你的看法"这类硬要回复的话术。X 会把它当互动诱饵，读者也会。这种写法 NR +1。

### SV — Save & send（收藏 / 私信价值）
*有没有人会收藏它留着以后用，或者私信 / 复制链接发给某个具体的人？*

对应行为：分享（私信、复制链接）；收藏数在公开指标里能看到。

- **0** — 读完就没用了（情绪、日常、纯观点）
- **3** — 有一条可用的信息，但用户不会为它专门回来
- **5** — 工具型内容：清单、模板、步骤、对比表、可复用的提示词 / 代码 / 数据；或者"这条正好说的是我朋友 X"

### RS — Repost & quote（转发 / 引用身份价值）
*转发这条，等于替转发者说了一句 ta 想说的话吗？引用这条，ta 有没有自己的话要加？*

对应行为：转发、引用。转发是身份表达；引用是"我同意 / 我反对 / 我补充"。

- **0** — 转发它对转发者没有任何好处，或者会暴露 ta 不想暴露的处境
- **3** — 中性可转
- **5** — 转发本身就是表态（圈内人的黑话 / 行业共同的痛点 / 一个大家早想说但没说清的判断）；或者天然适合被引用加评论

> 上游 cheat-on-content 在视频数据里发现："受众广"不等于"愿意转"——一个人人相关但转了会暴露处境的话题（如求职受挫）转发率反而最低。RS 直接测"愿意转"，不测"相关的人多不多"。

### DW — Dwell（停留密度）
*点开后读者愿不愿意停留读完？单位注意力里装了多少东西？*

对应行为：停留时长、点击后停留时长。

- **0** — 冗长、绕、一屏只有一个意思；或者空洞到没什么可停留的
- **3** — 能读完，节奏一般
- **5** — 每一行都在推进；thread 每条结尾都让人想看下一条；分段、留白、列表用得当，在手机上一屏一个节拍

单条短帖 DW 通常给 2-3——短帖的停留主要靠 HK 和 SV。

### FT — Follow trigger（关注转化）
*看完的人会不会点你头像看看你是谁，然后关注？*

对应行为：点主页、主页停留、关注作者。

- **0** — 换任何人发都一样；看不出作者是谁、为什么值得持续看
- **3** — 看得出作者在某个领域有东西
- **5** — 带着明确的"我是谁"：持续的系列 / 独有的一手经验或数据 / 一个鲜明的、会持续输出的视角——读者会想"这个人以后还会发这种东西"

### NF — Niche fit（圈层契合）
*这条和你的关注者、以及你想打进的那个圈子，平时在互动的东西有多近？*

对应机制：关注者时间线（in-network）是基本盘；破圈（out-of-network）靠检索把帖子推给"互动历史和这条内容相近"的人。主题漂移会让两头都落空。

- **0** — 和你过去发的、你的关注者关心的完全无关（突然发一条毫不相干的热点）
- **3** — 相关领域，但不是你的核心话题
- **5** — 正中你的核心话题，并且用的是这个圈子的语言

### NR — Negative risk（负反馈风险，**扣分项**）
*这条会不会让一部分看到的人点"不感兴趣"、静音、屏蔽、举报？*

对应行为：不感兴趣、静音作者、屏蔽作者、举报——这些在排序里是负权重，而且通常比正向行为的权重大。

- **0** — 没有风险
- **2** — 有争议，但争议在观点层面
- **3** — 互动诱饵话术、标题党、阴阳怪气针对具体群体
- **5** — 引战 / 人身攻击 / 误导性信息 / 刷屏式重复 / 明显的 spam 模式

NR 高不一定曝光低——愤怒也是流量。但它会伤关注者对你的长期信任，复盘时单独看"静音 / 取关"信号（数据可得时）。

## 不打分、但每条都要记的"发布条件"（协变量）

这些不是内容质量，但对曝光影响很大。预测 header 必须记录，`/cheatx-bump` 时可以用来解释残差：

| 协变量 | 取值 |
|---|---|
| 形态 | `single` / `thread` / `long` / `article` / `quote` / `reply` |
| 媒体 | 纯文字 / 图片 / 视频 / GIF / 投票 |
| 外链 | 有 / 无（2026 年 X 官方称已不再压外链，独立测量结论不一致——记下来让你自己的数据说话） |
| 发帖时段 | 本地时间 + 星期 |
| 发帖时粉丝数 | 整数 |
| Premium | none / basic / premium / premium_plus |
| 距上一条帖子 | 分钟（同一作者短时间连发会被打折） |
| 语言 | zh / en / mixed |
| 回复对象（仅 reply / quote） | 对方 handle 的粉丝量级 |

## Bucket 预测：倍数桶

不要预测一个具体数字。预测一个 bucket + 概率分布。

**基线（baseline）** = 同一形态最近 10 条已复盘帖子的曝光中位数（`state.baseline_impressions[form]`）。该形态不足 3 条 → 用 `all`；`all` 也没有 → cold-start 猜测（下面）。

| Bucket | 范围 | 含义 |
|---|---|---|
| `退步` | < 0.3× 基线 | 明显低于你的常态 |
| `持平` | 0.3 – 1× | 常态 |
| `命中` | 1 – 3× | 好于常态 |
| `小爆` | 3 – 10× | 破圈 |
| `大爆` | > 10× | 量级跃迁 |

每次预测给：最可能的 bucket、中枢（bucket 内的点估计，写成具体曝光数）、5 个 bucket 的概率（加起来 100%）。

### Cold-start 基线猜测（还没有任何自己的复盘数据时）

```
baseline_guess = max(100, 发帖时粉丝数 × 0.3)
```

这个数只是让 bucket 有个落脚点。第一条复盘回来后立刻被真实中位数替代。新号经常出现"粉丝很少但单条曝光是粉丝数 10 倍"——那是平台的新作者补偿，不是你的常态，别据此上调基线。

### 次要押注（完整预测必填，快押可选）

- **互动率区间**：(赞 + 转 + 引用 + 回复 + 收藏) ÷ 曝光，押 `<1%` / `1–3%` / `>3%`
- **收藏 / 赞比**：押 `<0.1` / `0.1–0.3` / `>0.3`（SV 高的帖子这个比值高）
- **回复数**：押一个区间（RP 的直接检验）

## 复盘窗口

默认 **T+48h**：For You 的候选过滤会丢掉 48 小时以前的帖子，之后曝光主要来自搜索、主页和转发长尾，基本停涨。T+48h 让你每天都能跑校准循环。

reply 形态同样 T+48h。长帖 / Article 用 [x-longform-zero.md](x-longform-zero.md) 的 T+7d。

## 打分形态细则

| 形态 | 怎么打 |
|---|---|
| `single` | 按上面定义直接打 |
| `thread` | HK 只看第一条（它决定有没有人点开）；DW 看整串；其他维度看整串 |
| `quote` | 被引用的原帖算上下文，只给**你加的那段话**打分。NF 看原帖话题和你的圈子是否契合 |
| `reply` | HK = 你这条回复在对方回复区里能不能被看见并点开；RP = 能不能引出对方或其他人的回应；FT 是 reply 的核心价值（别人因为你的回复来看你主页）。SV / DW 通常低 |
| `long`（帖内长文） | 如果账号主要发长帖，改用 x-longform-zero；偶尔发一条，HK 只看"显示更多"之前那段 |

## Cold-start 取样策略

前 5-10 条不是在做决策，是在**采集数据**：

1. **建立纪律**：每条发之前写下盲判断
2. **故意拉开维度组合**：一条 SV 主导（清单 / 模板）、一条 RP 主导（有分歧的判断）、一条 RS 主导（圈内共鸣）、一条 FT 主导（一手经验）、一条 HK 极强但内容一般——这样第一次 bump 才有信号可分
3. **每条都走完闭环**：跳过复盘 = 这条白发

| 校准样本 | 你能相信什么 |
|---|---|
| 0-4 | 啥都别信 |
| 5-14 | "哪个维度可能重要"的方向 |
| 15-39 | bucket 排序 |
| 40+ | 中枢开始可信 |

## 已知会打错的地方

1. **大号转发是外生冲击**：一条被大号转发或引用，曝光可以跳 30×，和内容分数关系不大。复盘时先查"曝光来源是否被单个转发主导"，是的话标 `exogenous_boost`，bump 时降权
2. **回复的曝光受对方帖子热度支配**：同一条回复挂在热帖下和挂在冷帖下没法比。reply 形态的基线单独算，并记录对方帖子的量级
3. **时效**：热点帖的曝光窗口可能只有几个小时。v0 没有时效维度（TM 是 v1 候选，见下）
4. **发帖间隔**：一小时连发三条，后两条被作者多样性衰减打折，分数再高也会偏低

## v1 候选维度（未进公式，仅供 bump 时探索）

- **TM — Timeliness（时效）**：话题是否正处在讨论高峰（0 = 常青；5 = 今天正在发生）。先在预测的"推理因素"里记录，样本够了再用 /cheatx-bump 验证要不要升正

## 打分速度

- 每个维度 20 秒。超过这个时间你是在合理化，不是在打分
- 相信第一个整数。在 3 和 4 之间犹豫就写 3 + 一句备注
- **先盲打，再看锚点**
