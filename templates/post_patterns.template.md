## ⚠️ Pattern 是工具箱，不是模具

每条 pattern 都只是"从已发样本反推的路径之一"。每条都套同一个模板，账号上限就是"稳定的中等表现"——真正破圈的帖子常常在 pattern 之外。

写之前先回答：**这条帖子最强的属性是什么？**再选 pattern。

## 通用 pattern 库（初始骨架，复盘后填具体）

### Pattern 1：第一行

**原则**：信息流里只露出第一屏。第一行必须独立成立——不读第二行也知道这条在说什么、为什么值得停。

**不要**："最近在思考一个问题……"、"分享一下……"、"关于 X，我有几点想法"。

已知常见的有效写法（哪种适合你账号要试）：
- **A. 数字 + 反差**："我用了 6 个月 X，最后只留下 3 个功能"
- **B. 结论先行**：第一句就是结论，后面是证据
- **C. 具体场景**：一个读者能代入的瞬间
- **D. 反常识断言**：一个让圈内人想反驳或想收藏的判断

### Pattern 2：thread 结构

- 第一条 = 完整的承诺（读完能得到什么）+ 为什么值得读。第一条决定有没有人点开
- 每条一个点，一条能独立被截图
- 编号（1/7）要不要用：看你圈子的习惯，复盘时对照
- 最后一条：回扣第一条的承诺 + 一句"我是谁 / 我持续写什么"（FT）。不要硬求转发

### Pattern 3：手机上的节奏

- 一行一个意思，段落之间空行
- 列表用 `-` 或数字，别用长段落
- 中文帖子少用长复合句；英文帖子少用从句堆叠
- 长帖每 3-5 段一个小标题或分隔

### Pattern 4：回复（reply）

- 早：对方发出后越早回复，在回复区越靠前
- 补充而不是附和："同意"没有价值；"补一个反例 / 一个数据 / 一个具体做法"才有
- 只回你核心话题里的帖子（NF）——回复是让对方的读者认识你，话题跑偏等于白回
- 回复里体现"我是谁"（FT），但不贴链接、不自我推销

### Pattern 5：引用（quote）

- 加立场，不要只写"这个"/ "说得好"
- 一句话说清你和原帖的关系：补充 / 反对 / 换个场景应用
- 原帖越热，你这句越要短

### Pattern 6：长帖 / Article

- 折叠前那一段 = 结论 + 承诺 + 读完的收获
- 小标题让人能扫读
- 结尾兑现开头的承诺；留一个读者能用自身经验回答的问题（RP）

### Pattern 7：媒体

- 图片里的字要在手机上看得清
- 数据截图 > 文字描述数据
- 视频前 2 秒决定是否继续播放
